# CRO Operations: Problems Worth Solving

## How a CRO Works (and Where It Breaks)

A Contract Research Organization runs trials on behalf of pharma/biotech sponsors. Their entire business is **coordination labor** — the exact thing agents replace.

---

## The CRO Value Chain

### 1. Business Development & Bid Defense

**What happens:** Sponsor sends RFP. CRO has 2-3 weeks to respond with a 200+ page proposal.

**Problems:**
- Proposal assembly pulls from 15+ internal systems — manual stitching
- Pricing is gut-feel; no data-driven model. Bids won/lost on pricing accuracy
- Bid/no-bid decisions waste 30%+ of BD effort on unwinnable RFPs
- CV matching (finding available staff with right therapeutic area + geography) takes days

**Agent opportunity:** RFP parsing → budget modeling → resource matching → proposal drafting agents. Win-rate prediction model. A top-10 CRO responds to 500-1000 RFPs/year at $50K-100K cost per response.

---

### 2. Study Startup (3-6 months — #1 sponsor complaint)

**Problems:**
- Country-level regulatory fragmentation (20 countries = 20 different workflows)
- Site contract negotiation is sequential and slow (fair market value, indemnification)
- Essential document collection nightmare (CVs, licenses, certifications from 50-200 sites)
- Milestone tracking across sites via massive spreadsheets

**Agent opportunity:** Country-specific regulatory agent + contract negotiation agent + document collection agent + startup dashboard agent. Reducing startup by 1 month = $1-5M saved per trial.

---

### 3. Site Monitoring (Largest CRO Cost Center)

**What happens:** CRAs visit sites to verify data, check compliance, resolve issues. A CRO might have 2,000-5,000 CRAs globally, each managing 5-10 sites.

**Problems:**
- Visit reports are 80% boilerplate — CRAs spend 4-6 hours writing each one
- Pre-visit preparation is manual (review queries, deviations, enrollment, prior findings)
- Risk-based monitoring is underutilized (CROs default to 100% SDV)
- Query management is a firehose — duplicates, low-priority, manual tracking
- CRA turnover is 25-30%/year; new CRAs take 6+ months to be productive

**Agent opportunity:**
- Visit report drafting agent
- Pre-visit briefing agent
- Intelligent query agent (auto-generates, de-duplicates, prioritizes)
- Risk signal agent (continuous RBQM scoring)
- CRA onboarding agent (captures institutional knowledge)

**ROI math:** Save each CRA 10 hrs/week × 3,000 CRAs × $75/hr = **$117M/year in labor savings for a single large CRO**

---

### 4. Data Management

**Problems:**
- Edit check programming is slow (hundreds of validation rules per study, often from scratch)
- Medical coding (MedDRA/WHODrug) auto-coders miss 20-30%, requiring manual review
- Data listings review is tedious pattern-matching
- Database lock is always late, delaying CSR and submission

**Agent opportunity:** Edit check generation agent + medical coding agent + data review agent + database lock readiness agent.

---

### 5. Project Management & Sponsor Communication

**Problems:**
- Status reporting pulls from CTMS, EDC, finance, resource systems manually
- Change orders are adversarial; scope creep documentation is poor
- Risk identification is reactive, not predictive
- PMs spend 60%+ of time in calls, not managing

**Agent opportunity:** Auto-reporting agent + scope tracking agent + predictive risk agent + meeting prep agent.

---

### 6. Financial Management & Revenue Recognition

**Problems:**
- Pass-through reconciliation (investigator payments, lab costs, shipping) is a mess
- Budget-to-actual tracking lags
- Investigator payments are slow (= poor site relationships = enrollment problems)
- Revenue forecasting is inaccurate (ASC 606 complexity)

**Agent opportunity:** Reconciliation agent + budget burn agent + investigator payment agent + revenue forecasting agent.

## Recommended Startup Wedge

**Product: CRA Copilot** — automates visit report writing, pre-visit briefing, and query management.

- Addresses the single largest cost center in CRO operations
- Immediate, measurable ROI (hours saved per CRA per week)
- Low regulatory risk (decision support, not autonomous)
- Every CRO has this exact same problem

**Pricing:** $500-1,500/CRA/month. A mid-size CRO with 1,000 CRAs = $6-18M ARR from one customer.

**Expansion path:** Study startup automation → project management intelligence → full CRO operating system.

**End state:** The "agent layer" that sits on top of every CRO's existing systems (Medidata, Veeva, Oracle) and orchestrates human + AI workflows across the trial lifecycle.
