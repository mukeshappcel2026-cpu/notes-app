## Gap Analysis Summary

| Sub-Vertical | AI Competition Level | Biggest Gap |
|---|---|---|
| Trial Design | Moderate (funded startups exist) | No multi-agent orchestration across design components |
| Regulatory Submission | Low (incumbents are doc management) | AI-drafted submissions don't exist |
| Patient Recruitment | High (very crowded) | Differentiation is hard |
| Trial Monitoring | Moderate (dominated by Medidata) | Intelligence layer on top of data capture missing |
| Pharmacovigilance | Low-Moderate (mostly legacy) | Real-time multi-source signal detection via agents |
| CSR / Medical Writing | Very Low (mostly early-stage) | **Biggest whitespace — no dominant player** |
| Supply Chain | Very Low (few startups) | Innovation trapped inside IRT vendors |
| Full Orchestration | Moderate (well-funded but unproven) | No one has cracked true multi-agent trial ops |
